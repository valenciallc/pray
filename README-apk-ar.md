# تطبيق أوقات الصلاة والأذان — دليل البناء والنشر

تطبيق عربي إسلامي متكامل: أوقات الصلاة والإقامة محسوبة ذاتياً داخل الجهاز
لجميع الدول العربية والإسلامية دون إنترنت، مع الورد القرآني، المسبحة،
الأذكار بأصنافها، دعاء اليوم، والنغمات القابلة للتخصيص.

## 1) ما الموجود في هذا المجلد

| الملف / المجلد | الوظيفة |
|---|---|
| `index.html` | التطبيق بالكامل في ملف واحد (الواجهة + الحساب + البيانات) |
| `sw.js` | عامل الخدمة: تخزين ملفات التطبيق للعمل دون إنترنت والتحقق من التحديثات |
| `manifest.json` | بيانات تثبيت التطبيق (PWA) |
| `prayer_update.json` | بيانات الإصدار (الرقم + SHA-256 + الحجم + التاريخ) — **تُولَّد تلقائياً** |
| `tools/release.py` | أداة الإصدار: مزامنة الأرقام، حساب البصمة، بناء `dist/`، والفحص |
| `dist/` | النسخة الجاهزة للنشر على GitHub Pages — **تُولَّد تلقائياً** |
| `السريحي.mp3` · `اقامة.mp3` | نغمتا الأذان والإقامة |
| `icon*.png` · `icon.svg` · `logo.png` · `icons/` | الأيقونات والشعار |

> **مهم:** لا يوجد حالياً مجلد `android/` ولا ملف APK داخل هذا المجلد.
> إشعارات الأذان الحقيقية (التي تعمل والتطبيق مغلق) تعتمد على جسر
> `window.AndroidUpdater` في غلاف أندرويد. إن لم يكن لديك مصدر الغلاف،
> انشر نسخة الويب من `dist/` كما في القسم 3: تعمل دون إنترنت بعد أول فتح،
> لكن التنبيهات الدقيقة وإذن البطارية تبقى خاصة بتطبيق أندرويد.

## 2) الإصدار الحالي

- **النسخة الحالية: 15**
- الرقم نفسه موجود في `prayer_update.json` و`sw.js` (`SW_VERSION`) و`index.html` (`APP_VERSION`) وهذا الدليل.
- التحديث الذاتي يتحقق من **SHA-256** قبل تخزين أي نسخة جديدة؛ لذلك لا تُعدّل `prayer_update.json` يدوياً أبداً.

## 3) نشر نسخة الويب (PWA) على GitHub Pages

1. شغّل: `python3 tools/release.py` — سيبني مجلد `dist/` ويحدّث بيانات الإصدار.
2. أنشئ مستودعاً عاماً على GitHub (مثلاً `prayer-app`) وارفع **محتويات `dist/`** فقط.
3. من المستودع: **Settings ← Pages ← Deploy from a branch** ← `main` ← `/ (root)` ← **Save**.
4. بعد دقيقة ستظهر رسالة خضراء برابط مثل `https://اسمك.github.io/prayer-app`.
5. افتح الرابط مرة واحدة على الإنترنت ليخزّن عامل الخدمة الملفات؛ بعدها يعمل دون إنترنت.
6. داخل التطبيق: الإعدادات ← «تحديث التطبيق من الداخل» ← ضع الرابط ← «حفظ رابط التحديثات».

## 4) إصدار تحديث جديد (الطريقة الصحيحة)

1. عدّل `index.html` أو أي ملف من الأصول.
2. شغّل `python3 tools/release.py`:
   - يرفع رقم الإصدار واحداً،
   - يحسب SHA-256 والحجم والتاريخ من الملف الفعلي،
   - يزامن `sw.js` و`APP_VERSION` والدليل،
   - يعيد بناء `dist/`.
3. شغّل `python3 tools/release.py --check` — يجب أن يظهر `✔ كل شيء متسق`.
4. ارفع محتويات `dist/` مرة أخرى إلى نفس المستودع (Replace).
5. التطبيقات المثبّتة ستجد الإصدار الجديد عند فتحه، وتتحقق من البصمة قبل التحديث. إن لم يكن هناك إنترنت يواصل العمل بالنسخة القديمة بلا مشكلة.

خيارات مفيدة:

```bash
python3 tools/release.py              # رفع الإصدار واحد (الافتراضي)
python3 tools/release.py --set 20     # فرض رقم إصدار معين
python3 tools/release.py --no-bump    # إصلاح البصمة فقط دون تغيير الرقم (للطوارئ)
python3 tools/release.py --check      # فحص الاتساق بدون أي تعديل
```

## 5) غلاف أندرويد وAPK (عند توفر مصدره)

إذا كان لديك مشروع `android/` (MainActivity.java وNotificationPlanner.java
وAlarmReceiver.java وAdhanService.java وBootReceiver.java):

1. ضع مجلد `android/` في جذر هذا المشروع، وتأكد أن `app/src/main/assets/`
   يحتوي على نسخة مطابقة من `index.html` وملفات الصوت.
2. افتح **Android Studio ← Open ← مجلد android** وانتظر تحميل المكوّنات أول مرة.
3. **Build ← Build App Bundle / APK ← Build APK**.
4. الناتج: `android/app/build/outputs/apk/release/app-release.apk`.
5. انسخ الـ APK إلى الهاتف واسمح بالتثبيت من مصادر خارجية. ثم:
   **الإعدادات ← البطارية ← التطبيق ← غير مقيّد (Unrestricted)** حتى لا تُقتل التنبيهات.
6. عند أول فتح تظهر معالج الصلاحيات: إذن الإشعارات ← تشغيل الخلفية ← التنبيهات الدقيقة ← إنهاء.

> ملف `keystore.jks` وكلمة المرور الموجودة في `app/build.gradle` هي هوية التطبيق؛
> احتفظ بها واستخدمها دائماً عند بناء إصدار جديد، وإلا اعتبره متجرُ الهاتف تطبيقاً مختلفاً.

## 6) استكشاف أخطاء التحديث

| العَرَض | السبب | الحل |
|---|---|---|
| «فشل التحقق من سلامة النسخة» | البصمة في `prayer_update.json` لا تطابق `index.html` | شغّل `python3 tools/release.py` ثم أعد رفع `dist/` |
| التطبيق لا يكتشف تحديثاً | رابط التحديثات خاطئ أو رقم `json` ليس أعلى من `APP_VERSION` | تأكد من الرابط في الإعدادات، ثم شغّل-release وأعد النشر |
| الإشعارات لا تعمل عند إغلاق التطبيق | نسخة الويب لا تدعم التنبيهات الدقيقة | استخدم غلاف أندرويد (القسم 5) مع السماح بالخلفية والبطارية غير المقيّدة |
| التطبيق لا يعمل دون إنترنت | لم يُفتح مرة واحدة على الشبكة ليخزّن عامل الخدمة | افتح الرابط مرة على الإنترنت ثم جرّب وضع الطيران |

## 7) بنية الملفات

```text
pray-main/
├── index.html            ← التطبيق الكامل
├── sw.js · manifest.json ← عامل الخدمة والتثبيت
├── prayer_update.json    ← بيانات الإصدار (مولّدة تلقائياً)
├── tools/release.py      ← أداة الإصدار والفحص
├── dist/                 ← نسخة النشر (مولّدة تلقائياً)
├── android/              ← غلاف أندرويد (غير موجود حالياً — أضفه عند توفره)
├── السريحي.mp3 · اقامة.mp3 · icons/ · logo.png · icon*.png
└── README-apk-ar.md      ← هذا الدليل
```
