# تطبيق أوقات الصلاة والأذان — دليل البناء والنشر

تطبيق عربي إسلامي متكامل: أوقات الصلاة والإقامة محسوبة ذاتياً داخل الجهاز
لجميع الدول العربية والإسلامية دون إنترنت، مع الورد القرآني، المسبحة،
الأذكار بأصنافها، دعاء اليوم، والنغمات القابلة للتخصيص.

## 1) ما الموجود في هذا المجلد

| الملف / المجلد | الوظيفة |
|---|---|
| `index.html` | هيكل الصفحة وحاجز الأخطاء فقط (بدون أنماط أو منطق مدمج) |
| `styles.css` | كل أنماط الواجهة، بما فيها الوضع الداكن والتباين العالي والجوال |
| `app.js` | منطق التطبيق بالكامل: الحساب، الأوقات، الأذكار، الإشعارات، والتحديث |
| `sw.js` | عامل الخدمة: تخزين ملفات التطبيق للعمل دون إنترنت والتحقق من بصماتها |
| `manifest.json` | بيانات تثبيت التطبيق (PWA) |
| `prayer_update.json` | بيانات الإصدار (الرقم + SHA-256 + الحجم + التاريخ) — **تُولَّد تلقائياً** |
| `tools/release.py` | أداة إصدار محلية: مزامنة الأرقام، حساب البصمة، بناء `dist/` للفحص، والتحقق |
| `tools/smoke_test.js` | اختبار دخان محلي يتحقق من ظهور البيانات بعد كل تعديل |
| `tools/sw_test.js` | اختبار محلي لعامل الخدمة: يرفض الملفات المتلاعب بها ويقبل النسخ الموثّقة |
| `السريحي.mp3` · `اقامة.mp3` | نغمتا الأذان والإقامة |
| `icon*.png` · `icon.svg` · `logo.webp` · `logo.png` | الأيقونات والشعار (WebP مع fallback PNG) |

> **مهم:** لا يوجد حالياً مجلد `android/` ولا ملف APK داخل هذا المجلد.
> إشعارات الأذان الحقيقية (التي تعمل والتطبيق مغلق) تعتمد على جسر
> `window.AndroidUpdater` في غلاف أندرويد. إن لم يكن لديك مصدر الغلاف،
> انشر نسخة الويب من ملفات الجذر كما في القسم 3: تعمل دون إنترنت بعد أول فتح،
> لكن التنبيهات الدقيقة وإذن البطارية تبقى خاصة بتطبيق أندرويد.

## 2) الإصدار الحالي

- **النسخة الحالية: 27** (غلاف أندرويد 1.3 / versionCode 4)
- من v27: لم تعد تظهر رسالة «متصفحك لا يدعم الإشعارات» في التطبيق؛ زر الجرس وزر «تفعيل الإشعارات» وزر «إشعار تجريبي» يستخدمون إشعارات النظام مباشرة.
- من v26: اللغة الافتراضية بعد التثبيت هي **English** وتُحفظ فوراً؛ وأي تغيير منها يُحفظ ويُستعاد عند إعادة الفتح أو تحديث المحتوى. منفذ الخادم المحلي صار ثابتاً كي لا تُفقد الإعدادات عند إعادة تشغيل التطبيق.
- من v25: زر الاستماع ينطق بالعربية عبر محرك أندرويد TTS الأصلي (لا رسالة «Speech is not supported»).
- من v24: `prayer_update.json` يحمل قائمة `assets` بكل الملفات، والمُحدِّث ينزّل منها أي ملف جديد مستقبلاً — لذلك يكفي تثبيت الـ APK مرة واحدة.
- من v23: التذكير يعمل تلقائياً بلا زر، والإيقاف من الإعدادات فقط. لا نافذة صلاحيات تلقائية عند الفتح. أزرار الصوت الفيزيائية تتحكم في تيار الأذان، والأذان يتوقف تلقائياً في الصامت أو «لا تُزعج».
- من v22: واجهة هادئة فاخرة — ٤ تبويبات فقط، قائمة «المزيد» للوظائف الثانوية، إعدادات متقدمة مخفية، ولوحة عاجية/ذهبية بخط أميري. وغلاف أندرويد يحدّث محتواه تلقائياً من GitHub.
- من v21: تحسينات الجوال والأداء — `format-detection`، `touch-action:manipulation`، شعار WebP محمّل مسبقاً مع PNG fallback، `spellcheck=false` لحقول الوقت، `will-change` أثناء التحريك فقط، حواف آمنة كاملة، وثيم يبدأ من إعداد النظام قبل ظهور الصفحة.
- من v20: التطبيق مقسّم إلى `index.html` + `styles.css` + `app.js` في الجذر، مع بصمة `SHA-256` مستقلة لكل ملف في حقل `files` داخل `prayer_update.json`.
- الرقم نفسه موجود في `prayer_update.json` و`sw.js` (`SW_VERSION`) و`app.js` (`APP_VERSION`) وهذا الدليل.
- التحديث الذاتي يتحقق من **SHA-256** لكل ملف قبل تخزينه؛ لذلك لا تُعدّل `prayer_update.json` يدوياً أبداً.

## 3) نشر نسخة الويب (PWA) على GitHub Pages

الدليل المفصّل: **`README-GITHUB-PAGES.md`**.

المستودع `valenciallc/pray` يخدم **ملفات الجذر** مباشرة من الفرع `main` (لا يوجد `dist/` ولا workflow داخل المستودع).

1. شغّل `python3 tools/release.py --check` محلياً — يجب أن يظهر `✔ كل شيء متسق`.
2. ادفع ملفات الجذر المحدّثة إلى `main`:
   ```bash
   git add index.html styles.css app.js sw.js prayer_update.json README-apk-ar.md README-GITHUB-PAGES.md CHANGELOG.md
   git commit -m "Prayer app v22 - calm elegant UI and self-updating Android shell"
   git push
   ```
3. من المستودع: **Settings ← Pages ← Source: Deploy from a branch ← main ← /(root) ← Save**.
4. افتح `https://valenciallc.github.io/pray/` مرة واحدة على الإنترنت ليخزّن عامل الخدمة الملفات؛ بعدها يعمل دون إنترنت.
5. اضغط زر 🔔 في الشريط لتفعيل إشعارات المتصفح. الإعدادات أصبحت مختصرة: الحساب والإشعارات والمظهر فقط، والباقي تحت «إعدادات متقدمة».
6. داخل التطبيق: الإعدادات ← إعدادات متقدمة ← «تحديث التطبيق من الداخل» ← ضع الرابط ← «حفظ رابط التحديثات».

## 4) إصدار تحديث جديد (الطريقة الصحيحة)

1. عدّل `index.html` أو أي ملف من أصول الجذر.
2. شغّل `python3 tools/release.py` محلياً:
   - يرفع رقم الإصدار واحداً،
   - يحسب SHA-256 والحجم والتاريخ من الملف الفعلي،
   - يزامن `sw.js` و`APP_VERSION` والدليل،
   - يعيد بناء `dist/` محلياً للفحص فقط (لا يُرفع إلى المستودع).
3. شغّل `npm test` (اختبار عامل الخدمة + اختبار الدخان) ثم `python3 tools/release.py --check`.
4. انسخ ملفات الجذر المحدّثة واعمل commit و push إلى `main`؛ سيظهر التحديث على Pages خلال دقيقة.
5. التطبيقات المثبّتة ستجد الإصدار الجديد عند فتحه، وتتحقق من البصمة قبل التحديث. إن لم يكن هناك إنترنت يواصل العمل بالنسخة القديمة بلا مشكلة.

خيارات مفيدة:

```bash
python3 tools/release.py              # رفع الإصدار واحد (الافتراضي)
python3 tools/release.py --set 20     # فرض رقم إصدار معين
python3 tools/release.py --no-bump    # إصلاح البصمة فقط دون تغيير الرقم (للطوارئ)
python3 tools/release.py --check      # فحص الاتساق بدون أي تعديل
```

## 5) غلاف أندرويد وAPK (جاهز في `android/`)

المشروع موجود الآن داخل المستودع، وهو غلاف WebView يفتح المحتوى المحلي عبر خادم HTTP داخلي على `127.0.0.1` (منفذ عشوائي) حتى تعمل `fetch` و service worker و localStorage بأصل حقيقي. المحتوى **يتحدّث تلقائياً** من GitHub دون تثبيت APK جديد.

### كيف يعمل التحديث الذاتي
1. عند أول تشغيل تُنسخ أصول الويب من `assets/www/` إلى `filesDir/www/`. مهمة Gradle `copyWebAssets` تنسخ ملفات الجذر تلقائياً عند كل بناء.
2. عند الفتح (مرة كل ٦ ساعات كحد أقصى) يفحص `prayer_update.json` من `https://raw.githubusercontent.com/valenciallc/pray/main`.
3. إن كان رقم الإصدار أعلى، ينزّل كل الملفات إلى مجلد مؤقت، ويتحقق من `SHA-256` لـ `index.html` و`styles.css` و`app.js` والحجم، ثم يستبدل المجلد ذرياً ويُعيد تحميل الصفحة بعد إلغاء عامل الخدمة القديم.
4. عند الفشل يُبقى المحتوى القديم كما هو، وتظهر رسالة خطأ فقط. التحديثات عبر HTTPS فقط.

### البناء محلياً
```bash
cd android
export ANDROID_HOME=$HOME/Android/Sdk
./gradlew assembleRelease
```
الناتج: `android/app/build/outputs/apk/release/app-release.apk` (موقّع عند وجود keystore محلي).

لإنشاء هوية توقيع محلية مرة واحدة (لا تُرفع إلى Git):
```bash
keytool -genkeypair -keystore android/app/pray-release.keystore -alias pray \
  -keyalg RSA -keysize 2048 -validity 10000
```
ثم أضف في `android/local.properties` (مستبعد من Git):
```
sdk.dir=/path/to/Android/Sdk
keystore.file=pray-release.keystore
keystore.password=...
keystore.alias=pray
keystore.keyPassword=...
```
> احتفظ بالـ keystore وكلمة المرور؛ فقدانها يعني أن التحديث التالي سيُعتبر تطبيقاً مختلفاً.

### على الهاتف
انسخ الـ APK واسمح بالتثبيت من مصادر خارجية، ثم:
**الإعدادات ← البطارية ← التطبيق ← غير مقيّد (Unrestricted)** حتى لا تُقتل التنبيهات.
لا تظهر نافذة صلاحيات تلقائية عند الفتح. افتح **الإعدادات ← إعدادات متقدمة ← 🛠️ تفعيل الصلاحيات** فقط إذا أردت منح الإشعارات أو التنبيهات الدقيقة أو تجاهل «لا تُزعج».

### الصوت وأوضاع الهاتف (أندرويد 1.3)
- **أزرار الصوت الفيزيائية:** تضبط مستوى الأذان مباشرة (تيار `STREAM_ALARM`) ويظهر مؤشر النظام، حتى أثناء تشغيل الأذان.
- **الصامت والاهتزاز و«لا تُزعج»:** لا يُشغَّل الأذان صوتياً، ويتبقى الإشعار والاهتزاز. إن بدأ الأذان ثم فعّلت الوضع الصامت يتوقف فوراً.
- **التذكير:** يعمل تلقائياً من أول فتح؛ لإيقافه استخدم مفتاح «تفعيل التذكير» في الإعدادات ← الإشعارات فقط.
- **النطق:** زر «استماع» ينطق الأذكار عبر محرك أندرويد TTS بالعربية؛ إن لم تتوفر أصوات عربية على الجهاز يستخدم الإنجليزية كبديل. يحتاج الجهاز أن يكون الصوت غير صامت.

### اللغة (من v26)
- الافتراض عند أول تثبيت: **English**، ويُحفظ تلقائياً.
- تغيير اللغة (زر اللغة أعلى الشاشة أو «اللغة» في الإعدادات) يُحفظ فوراً ويُستعاد عند إعادة فتح التطبيق أو بعد أي تحديث محتوى.
- أصل WebView يستخدم منفذاً محلياً محفوظاً، لذلك لا تُفقد الإعدادات عند إعادة تشغيل التطبيق.

### الإشعارات (من v27)
- اضغط زر الجرس أعلى الشاشة أو فعّل «الإشعارات» من الإعدادات ← الإشعارات؛ سيُطلب إذن الإشعارات من النظام عند الطلب فقط.
- «إشعار تجريبي» في الإعدادات المتقدمة يُرسل إشعاراً نظامياً حقيقياً. لا تظهر رسالة «متصفحك لا يدعم الإشعارات» داخل التطبيق.
- الأذان والإقامة تُجدول عبر تنبيهات النظام حتى لو كانت الصفحة مغلقة (مع السماح بالبطارية غير المقيّدة).

> ملاحظة مهمة: هذا الغلاف يحدّث **المحتوى** فقط. تحديث ملف APK نفسه يحتاج موافقة المستخدم على التثبيت في أندرويد الحديث، ولا يمكن تنفيذه صامتاً دون صلاحيات نظام/root.

## 6) استكشاف أخطاء التحديث

| العَرَض | السبب | الحل |
|---|---|---|
| «فشل التحقق من سلامة النسخة» | بصمة أحد الملفات في `prayer_update.json` لا تطابق ملفه على الخادم | شغّل `python3 tools/release.py` ثم ارفع `index.html` و`styles.css` و`app.js` و`prayer_update.json` معاً |
| التطبيق لا يكتشف تحديثاً | رابط التحديثات خاطئ أو رقم `json` ليس أعلى من `APP_VERSION` | تأكد من الرابط في الإعدادات، ثم شغّل `tools/release.py` وأعد النشر |
| الإشعارات لا تعمل عند إغلاق التطبيق | نسخة الويب لا تدعم التنبيهات الدقيقة | استخدم غلاف أندرويد (القسم 5) مع السماح بالخلفية والبطارية غير المقيّدة |
| التطبيق لا يعمل دون إنترنت | لم يُفتح مرة واحدة على الشبكة ليخزّن عامل الخدمة | افتح الرابط مرة على الإنترنت ثم جرّب وضع الطيران |

